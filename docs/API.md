# Search Typeahead API Documentation

This document outlines the available REST endpoints for the Search Typeahead system.

---

### `GET /suggest`
Fetches the top 10 autocompletion suggestions for a given search prefix, ranked by their current trending score. Uses an in-memory Trie data structure and consistent-hashing caching layer for <1ms latency.

* **Path:** `/suggest?q=<prefix>`
* **Method:** `GET`
* **Request Format:** 
  * Query Parameter: `q` (string) - The prefix to search for.
* **Response Format:**
  ```json
  {
    "suggestions": [
      {
        "query": "elden ring",
        "count": 41032
      }
    ]
  }
  ```
* **Example:**
  ```bash
  curl -X GET "http://localhost:3001/suggest?q=eld"
  ```

---

### `POST /search`
Submits a user's finalized search query. The system utilizes a deferred batch writer to aggregate requests in memory and flushes them to the data store atomically (every 50 requests or 10 seconds).

* **Path:** `/search`
* **Method:** `POST`
* **Request Format:**
  ```json
  {
    "query": "elden ring"
  }
  ```
* **Response Format:**
  ```json
  {
    "message": "Searched"
  }
  ```
* **Example:**
  ```bash
  curl -X POST http://localhost:3001/search -H "Content-Type: application/json" -d '{"query":"elden ring"}'
  ```

---

### `GET /trending`
Retrieves the top 10 hottest searches over a sliding 24-hour window. Ranks are generated by blending overall historical search volume with recent search velocity.

* **Path:** `/trending`
* **Method:** `GET`
* **Request Format:** None
* **Response Format:**
  ```json
  {
    "trending": [
      {
        "query": "hollow knight",
        "score": 0.8024,
        "recentSearches": 20,
        "totalCount": 728884
      }
    ]
  }
  ```
* **Example:**
  ```bash
  curl -X GET "http://localhost:3001/trending"
  ```

---

### `GET /cache/debug`
A diagnostic endpoint demonstrating the internal state of the Consistent Hash ring. Returns the logical cache node a prefix maps to, and whether the cache is currently warm or expired.

* **Path:** `/cache/debug?prefix=<prefix>`
* **Method:** `GET`
* **Request Format:**
  * Query Parameter: `prefix` (string) - The exact prefix string to inspect.
* **Response Format:**
  ```json
  {
    "prefix": "el",
    "assignedNode": "cache-node-3",
    "hit": true,
    "cachedAt": "2026-06-20T10:56:00.867Z",
    "ttlRemaining": 60
  }
  ```
* **Example:**
  ```bash
  curl -X GET "http://localhost:3001/cache/debug?prefix=el"
  ```

---

### `GET /cache/stats`
Returns aggregated load balancing metrics detailing cache hits and misses across the simulated server cluster.

* **Path:** `/cache/stats`
* **Method:** `GET`
* **Request Format:** None
* **Response Format:**
  ```json
  {
    "hitRate": "33.3%",
    "hits": 10,
    "misses": 20,
    "totalRequests": 30,
    "nodesCount": 3
  }
  ```
* **Example:**
  ```bash
  curl -X GET "http://localhost:3001/cache/stats"
  ```

---

### `GET /stats`
Exposes core telemetry regarding the global Trie size and the efficiency of the `BatchWriter` queue preventing lock contention.

* **Path:** `/stats`
* **Method:** `GET`
* **Request Format:** None
* **Response Format:**
  ```json
  {
    "totalQueries": 120000,
    "totalSearchSubmissions": 87839480,
    "batchWriter": {
      "bufferSize": 0,
      "totalFlushes": 1,
      "totalWritesReduced": 99,
      "lastFlushAt": "2026-06-20T10:43:06.149Z"
    }
  }
  ```
* **Example:**
  ```bash
  curl -X GET "http://localhost:3001/stats"
  ```
